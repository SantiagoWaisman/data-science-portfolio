# Data Science Portfolio

Repositorio donde documento, paso a paso y de forma pública, mi camino hacia trabajar en ciencia de datos. Vengo de haber hecho varios cursos sueltos en los últimos años, pero armé un programa propio de 6 meses (inicio: septiembre 2026) para consolidar esos conocimientos de manera ordenada, desde los fundamentos hasta un portfolio real.

## Contenido

- **01_variables_tipos_operadores.ipynb** — Variables, tipos de dato (`int`, `float`, `str`, `bool`), operadores, `TypeError` vs `ValueError`, condiciones de borde.
- **02_control_de_flujo_listas.ipynb** — `if/elif/else`, operadores lógicos (`and`/`or`), listas, bucles `for` (por índice y por valor).
- **03_funciones.ipynb** — Funciones (`def`, parámetros, `return`), reutilización de lógica.

## En progreso

Este repo se actualiza semana a semana a medida que avanzo con SQL, Power BI, estadística y Machine Learning. Próximos proyectos: análisis exploratorio de datos (EDA) y dashboards.
